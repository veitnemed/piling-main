# Практика по проекту

Короткие задания на 5 минут для тренировки быстрого поиска решений и улучшения архитектуры проекта:

1. **Упростить расчёт спектральной энергии.** Убрать неиспользуемый аргумент `freq_vector` из `calculate_spectrum_energy` и обновить вызовы в `calculate_spectrum_SNR`. Проверить, что рассчитанный SNR не изменился.
2. **Проверять входные данные при расчёте SNR.** В `calculate_spectrum_SNR` обнаруживать массивы разной длины и случай, когда частотная маска не выбрала ни одного отсчёта. Для этих случаев выбрасывать `ValueError`; нулевой сигнал и взаимное сокращение отсчётов не путать с пустым массивом.
3. **Устранить побочный эффект в серии экспериментов.** В `stat_vs_params` не менять переданный конфиг и состояние его генератора случайных чисел при `is_CRN=False`. При `is_CRN=True` сохранять одинаковую реализацию шума для разных значений параметра. Для независимой копии конфига использовать `deepcopy`.
4. **Поддержать комплексные сигналы в ковариационной матрице.** В `get_covariation_matrix` использовать эрмитово сопряжение: `matrix @ matrix.conj().T / N`. Проверить, что для вещественных данных результат прежний, а для комплексных матрица эрмитова.

Связанный разбор в `notebooks/3_SNR_vs_f.ipynb`: SNR в линейной шкале, сумма квадратов модулей спектральных отсчётов и выбор частотной области маской.
